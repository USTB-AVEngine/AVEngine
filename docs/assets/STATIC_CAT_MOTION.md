# Static cat rigging and explicit movement qualification

Fit the selected target's own landmark positions in Blender, after a constant four-paw support-plane transform. Retarget only the CC0 Quaternius Cat animation; retain the registered target mesh, dimensions and PBR. Source meshes, registries and other worktrees are read-only. Large outputs and runtime configuration stay outside Git. The output inventory is private and a successful export is a candidate, not admission.

`tools/assets/blender_rig_static_cats.py` takes `--roster`, `--inventory`, `--template-motion`, `--asset`, and a new `--output`. Run with Blender background mode, one thread and `--python-exit-code 2`. Heat weights are attempted first; unresolved target vertices use envelopes. Harmonic regularization shares weights across welded coordinates without altering topology or UVs. All standard glTF `JOINTS_n` / `WEIGHTS_n` sets are retained. Distal soles and the actual mouth neighbourhood have fixed ownership. Target joint positions and weights are not copied from the donor.

`blender_check_cat_rig.py` independently reads the exported GLB. It measures the Idle self-intersection baseline, every baked Walking frame, heading and physically rotated 180/90-degree mesh controls, fixed support vertices, floor clearance, mouth attachment and edge stretch. Counts are informational only. Acceptance follows the owner 02:3x visible-penetration rule described below. The numerical shared-vertex exclusion remains 10 nm. The source surface is never repaired. Edge stretch remains limited to 1.5; native foot, heading and penetration limits remain those in `animal_motion/checks.py`.

Then use the committed animal-motion compiler and Habitat tools. `replay_animal_motion_bounded.py --blender BLENDER ...` is an optional bounded-lifetime replay for dense animated meshes: it runs small consecutive blocks in fresh Habitat processes, checks the actual drawable bounding box against that frame's posed vertices, and merges exactly all 145 global frame indices through the original validators. Default `run_habitat` behavior remains a single full replay. The bounded tool retains five real pose keyframes; other distinctly named streamed links are overwriteable storage and are not archived frame poses. `blender_check_cat_native_skin.py` checks every actual native input skin in a private bounded stream, retaining quantitative results and per-frame hashes. Neither partial blocks nor incomplete frame sequences qualify.

If target rigging or animation geometry fails, keep its evidence and use `slide_no_animation` on the unchanged registered static mesh. `compile_static_animal_slide.py` checks 145 flat-ground frames using the original explicit slide mode. `check_static_cat_geometry.py` measures source overlaps; rigid translation preserves edge lengths, seams and intersections exactly. Sliding makes no planted-paw gait claim. Native floor rays, full-body original-stage clearance, navigation, silhouette, mouth readback, actual 180/90-degree drawable controls and moving-source audio are still mandatory.

Audio uses three independent fresh native references per midpoint, the unchanged energy/direction/delay/DRR/RT60 gates, and a real +6 dB failure control. Stop after two failed intervals and diagnose before refinement. Only byte-identical unmodified midpoint references can become finer endpoints, and new midpoints require three new independent references. `qualify_animal_audio_parallel.py --immutable-cache-root OWN` optionally hardlinks immutable owned NPY arrays across rounds to limit storage; the SQLite database is copied independently. It changes storage only, not samples, comparisons or thresholds.

Final admission must bind the same native mouth trajectory, listener, room, runtime and audio receipt. Record `motion_mode`, `joint_animation_present`, rejection reason and animation attempts. An execution or resource error is reported as unverified, not proof that an asset has no possible animation. A single room's success does not admit other rooms. Never modify global registrations or push as part of this workflow.


The owner rule issued at 2026-10-14 02:3x SGT supersedes all earlier self-intersection count gates. Counts are diagnostic only. Fixed torso/head/tail/four-leg regions have newly exposed contacting area <=25 mm² per frame and new penetration depth <=2 mm. Internal new crossings within one region have depth <=2 mm. The area measurement is conservative: half the summed unique exposed contacting triangle areas; it is an upper bound, not a relaxed threshold. Exposed triangles are selected from unchanged binding geometry by global surface rays along normals and oblique exterior directions; artificial anatomical cut boundaries do not expose internal layers. Depth baselines compare the same material vertex and opposing face. Open region cuts without actual exterior crossings are not treated as closed volumes. Interregion depth checks the complete exposed material region against the opposing outward surface, relative to each material vertex in the binding pose, including fully contained regions. No source surface is repaired. All gait, native readback, audio and negative-control gates remain unchanged.

The motion-only donor is Quaternius Cat.blend, Walking, from Animal Pack Vol.2, licensed CC0 by its author at https://opengameart.org/content/animated-animales-low-poly. Target meshes, proportions, joint locations and weights remain target-native. Closed-region reference depths use the binding volume; open regional cuts use the same material face plane. Real closed-box containment, 1/3 mm internal sheet cases and rigid transforms are exercised by the retained Blender calibration before use.
