# 交接 · 同学 B:干声素材岗(20260830)

> 你的产出:给每类"声音事件"找/录**干声**片段(没有混响、没有背景底噪的纯净声)。
> 混响由我们的房间声学引擎去加——素材自带混响会叠加两遍,直接废。
> 这是当前**最缺人的岗**:需求 38 类,库存只有 1 条(狗叫种子)。

## 访问

```
ssh -L 8765:127.0.0.1:8765 <你的服务器别名>
```

浏览器开 http://localhost:8765 → 页脚"声音素材库"(/studio/sounds)。
页面上就是红绿缺口表:红 = 这类一条都没有。你的目标 = 把红变绿。

## 文件往哪放、长什么样

库根:`/data/avengine_external/assets/sound_library_v1/`

```
sound_library_v1/
  dog_bark/                    <- 事件类名,用页面缺口表里的词(资产档案的词表)
    golden_bark_01/
      clip.wav                 <- 干声本体
      clip.json                <- 旁车,四个字段见下
```

旁车 `clip.json`:

```json
{
  "event_classes": ["dog_bark"],
  "source": "自录 / freesound.org/xxx 的 URL / 数据集名",
  "license": "CC0 / CC-BY-4.0(注明作者) / 自录自有",
  "dry": true,
  "notes": "可选:一句备注"
}
```

放进去刷新页面,红格自动变绿,wav 头信息(采样率/声道/时长)机器自动读出显示。

## 格式与授权(硬要求)

- **干声**:无混响、无底噪。录音环境越"死"越好(被子棚/衣柜/近麦);网上素材选
  anechoic/dry/close-mic 标签的。
- 管线消费 **16 kHz 单声道 PCM wav**;其他采样率**可以先入库**,登记进正式 registry
  时我统一重采样——别为格式卡住收集。
- **license 必须写**:优先 CC0、CC-BY(记作者)、或自录。来路不明的不收——这是要进
  论文数据集的,授权断链整批报废。
- 单条 1–10 秒即可;同类多条更好(先做到每类 ≥1 条,再回头加深)。

## 排优先级

页面缺口表按"多少资产在等这类声音"排序,从上往下打就是最优路径。

## 预告(先知道,不用现在做)

题型全案里将新增"说话内容题"("第一个说话的人说了什么"),届时需要**带逐字转写的语音干声**
(旁车会加 `transcript` 字段,格式规范我到时候给)。收集时如果顺手碰到干净的短句语音素材,
可以先囤,license 规则同上。

## 遇到问题

页面顶部有格式要求原文;拿不准一条素材算不算"干",传上来在群里贴路径,我用工具量给你看。
