# 给同学 B 的说明:收集声音素材(2026-08-30)

你负责的是:给各种"声音事件"收集**干净的声音片段**。比如狗叫、猫叫、敲门声、
水壶烧开的声音。这是现在最缺人手的活:一共要 38 种声音,现在只有 1 种有货。

## 什么叫"干净"

就是**没有回声、没有背景噪音**的声音。原因:回声(混响)是我们的程序根据房间
形状自己算出来加上去的;如果素材本身就带回声,等于回声加了两遍,那条素材就废了。

- 网上找素材:挑标着 dry、anechoic、close-mic(近距离收音)这类字眼的;
- 自己录:嘴或声源离麦克风近一点,在铺满被子的小空间或者衣柜里录,效果最好。

## 先把页面打开

在你自己电脑的终端里跑这一条(尖括号换成你自己的服务器别名):

```
ssh -L 8765:127.0.0.1:8765 <你的服务器别名>
```

浏览器打开 http://localhost:8765 ,点页面最底下的"声音素材库"。
页面上是一张表:**红色格子就是还缺的声音种类**。你的目标就是把红的变绿。
表是按"多少个模型在等这种声音"排的,从最上面开始做就是最优顺序。

## 文件怎么放

库的根目录在服务器上:`/data/avengine_external/assets/sound_library_v1/`

每条素材一个文件夹,里面一个 wav 一个小 json:

```
sound_library_v1/
  dog_bark/              <- 声音种类的名字,照抄页面表格里的写法
    golden_bark_01/      <- 这条素材你自己起个名
      clip.wav           <- 声音本体
      clip.json          <- 小说明文件,照下面抄
```

`clip.json` 照这个改:

```json
{
  "event_classes": ["dog_bark"],
  "source": "如果是网上下的,顺手把网址贴在这;自己录的写'自录'",
  "dry": true
}
```

放好之后刷新页面,那个格子就自己变绿了,声音的时长采样率机器会自动读出来显示。

## 格式

- 一条 1 到 10 秒就够;同一种声音多录几条更好,但先保证每种至少有 1 条,再回头加量。
- 最理想是 16kHz 单声道的 wav。**不是也没关系,先放进来**,后面我统一转格式,
  别为这个卡住。

## 放完素材跑一下质检(重要,能省你很多返工)

放完一批新素材,在服务器上跑这一条:

```
cd /data/jzy/code/AVEngine-lead-a
/data/jzy/miniconda3/envs/avengine-habitat-runtime/bin/python tools/assets/qc_sound_library.py
```

它会把每条素材量一遍,结论直接显示在网页上每条素材旁边:绿章"机器质检 ✓"就是没问题,
黄的"有提醒"是能用但最好换,红的"不可用"必须换掉。机器会用大白话告诉你哪里不对,比如
"削波严重:3.2% 的采样点顶到最大值,声音已经失真"、"直流偏移 0.36,这条文件是坏的"、
"声音停下后还拖了 3.7 秒才衰减,可能是在房间里录的"。

**同一段声音不要复制到多个文件夹**。一条录音可以同时算好几个种类(比如闹钟的"嘀"
既是 alarm_beep 也是 alarm_clock),正确做法是**只放一份文件**,在旁车 json 的
event_classes 里把几个种类都写上:

```json
{"event_classes": ["alarm_beep", "alarm_clock"], "source": "...", "dry": true}
```

复制成两份的话,系统会以为这是两段不同的声音,可能把完全一样的音频同时放给房间里的
两个不同物体,那道题就没有答案了。网页上会用黄字提示哪些是重复的。

## 清洗这一步已经做好了,你不用管

我写了个脚本统一处理格式,你放进来的原始文件**一个都不会被改动**,处理后的副本放在
`/data/avengine_external/assets/sound_library_v1_prepared/`。它做四件事:去掉直流偏移、
带抗混叠滤波转成 16 kHz 单声道(直接抽点会让高频折回来污染信号,所以必须滤)、剪掉首尾
静音(前面留 30 毫秒余量,不会削掉起音)、峰值统一归到 −3 dBFS。每条改了什么都记在
`prepared_manifest.json` 里,包括加了多少增益,随时可查可还原。

你收完新素材,跑完质检以后再跑这一条就行:

```
cd /data/jzy/code/AVEngine-lead-a
/data/jzy/miniconda3/envs/avengine-habitat-runtime/bin/python tools/assets/prepare_sound_library.py
```

**质检判红的会被自动跳过、不做处理**——处理不能修复失真,坏素材只能换。重复的文件也
只处理一份,另一份记成别名。
