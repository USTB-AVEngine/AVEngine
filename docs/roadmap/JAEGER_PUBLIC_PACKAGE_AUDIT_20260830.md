## 一、论文声明(arXiv 2602.18527v3,ICML 2026)

- 声学:"SoundSpaces 2.0 renders multi-channel spatial audio by
  simulating room impulse responses (RIRs)……bidirectional path
  tracing……direct sound and higher-order effects, including
  reflections, transmission, diffraction, and air absorption"。
- 数据:61k 样本,同步 RGB-D、四通道一阶全景声(FOA)、3D 标注;相机与
  声源均静态。
- 论文描述 val split 含 **15 个场景**;实测包内为 **14 个场景**(差异
  记录于第四栏)。

## 二、代码路径(github.com/liuzhan22/JAEGER,20260830 查证)

- 公开包托管 HuggingFace `tsinghua-ee/JAEGER/datasets/SpatialSceneQA`:
  train 86.4GB / val 2.62GB / test 2.86GB 三个 tar.gz。
- **发布形态是 RIR 本体**:README 指引用户用
  `data/data_tools/conv_ir_speaker_foa.py` 将 RIR 与 LibriSpeech 干声
  卷积得到 FOA 语音。
- 卷积脚本查证:不重采样(采样率随干声,LibriSpeech 为 16kHz)、RIR 不
  归一化、全长卷积不截断——**下游音频的声学特性完全等于 RIR 的特性**。
- 仓库无 SoundSpaces 渲染/生成代码,渲染配置无法从代码侧核对。

## 三、公开包实测(完整 val 包,2,450 条,14 场景全覆盖)

**方法与可重复性**:完整下载 val 包(2.5GB)并解出全部 `ir*.npy` 与
`metadata.json`;分析脚本**已落库**——`tools/audit/audit_jaeger_rir.py`,
其头部固定声明全部算法参数:采样率主口径 16kHz(依据:官方卷积脚本不
重采样、干声为 16kHz;44.1kHz 口径同步换算)、四通道能量和、直达窗 =
峰前 16 / 峰后 40 采样(16k 口径 1.0/2.5ms)、Schroeder 逆积分衰减曲线、
无底噪补偿(本批尾部为数值零,无需;脚本注明移植真实录音时的限制)、
T20 = −5→−25dB 线性拟合外推、异常显式记录不静默。逐条数字
`rir_audit_val_full.csv`(2,450 行),按场景汇总
`rir_audit_summary.md`(脚本自动生成)。复现:

```
python3 tools/audit/audit_jaeger_rir.py --input <解包目录> \
    --out-csv rir_audit_val_full.csv --out-summary rir_audit_summary.md
```

**格式与计数交叉核验(R2.1 按全量修正)**:每条 shape
(4, 2086–2247) float64 FOA;容器长度中位 2,183 采样(16kHz 口径
≈136ms)。计数:task1 单源目录 1,000 个(各一条 `ir.npy`)+ task2
双源目录 725 个(各 `ir_male`+`ir_female` 两条)= 2,450 条,**与公开
annotation 的样本计数(task1=1000、task2=725)交叉一致**;加载失败 0。

**核心测量(全体 2,450 条)**:

| 指标 | 数值 | 含义 |
| --- | --- | --- |
| 峰后衰减 60dB 所需 | **中位 4 采样(0.25ms@16k);P95 = 4;最大 5** | 直达峰之后不足三分之一毫秒,能量即衰减百万分之一 |
| 到 −20/−40/−60dB 交叉点 | 几乎同点 | 悬崖式衰减,无混响缓坡 |
| 混响时间 T20 | **可计算条数 0 / 2,450** | 不存在可拟合的衰减坡 |
| 直达窗/其余能量比 | **中位 111.9dB,最小 106.6dB** | 直达之外能量低约 11 个数量级(可闻反射通常在 −5~20dB 区间) |
| 后半段能量占比 | 最大 1.5×10⁻⁴⁶% | 数值残渣 |

**按场景分层**:14 个场景(条数 67–394 不等)**全部同构**——各场景
峰后→−60dB 中位 2–4 采样、最大 4–5 采样,DRR 中位 110.7–117.0dB,
T20 可算条数每场景均为 0。逐场景表见 `rir_audit_summary.md`。

**实测结论(范围限定于 val 包)**:val 包全部 2,450 条 RIR 由**直达
分量主导**:含传播延迟(峰位与源距吻合)、距离增益与 FOA 方向编码,
但**未观察到可测的反射或混响衰减**。用这些 RIR 卷积出的语音,其房间
声学等效无回声(anechoic-equivalent)渲染。两种采样率口径(16k/44.1k)
下结论一致。
