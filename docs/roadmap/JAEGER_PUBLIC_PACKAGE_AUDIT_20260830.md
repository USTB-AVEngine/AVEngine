# JAEGER 公开数据包声学审计(20260830)

> **目的**:全案 v3 悬置的待办——内部记录称"JAEGER 公开数据没有混响",
> 而其论文声称完整房间声学仿真,两说矛盾,写论文对比表前必须实测。
> 按 owner 定的审计标准执行:先核官方仓库/生成代码/公开包内容;只有拿到
> RIR(房间脉冲响应)或干声/收声配对时,才把能量衰减类指标当混响证据;
> 报告分四栏——论文声明 / 代码路径 / 公开包实测 / 仍无法验证。
> **结论先行:矛盾解决,两边都"对"——论文说的是仿真管线的能力,公开包
> 里实际发布的 RIR 是纯直达脉冲,没有任何可测的房间声学。内部记录被
> 实测支持,且比原印象更极端。**

## 一、论文声明(arXiv 2602.18527v3,ICML 2026)

- 声学:"SoundSpaces 2.0 renders multi-channel spatial audio by
  simulating room impulse responses (RIRs)……bidirectional path
  tracing……direct sound and higher-order effects, including
  reflections, transmission, diffraction, and air absorption"——
  声称建模直达声与高阶效应(反射、透射、衍射、空气吸收)。
- 数据:61k 样本,每样本含同步 RGB-D、四通道一阶全景声(FOA)、3D 标注;
  相机与声源均为静态采样(一个接收位姿 + 1–4 米内固定源)。

## 二、代码路径(github.com/liuzhan22/JAEGER,20260830 查证)

- 公开包托管于 HuggingFace `tsinghua-ee/JAEGER/datasets/SpatialSceneQA`,
  三个压缩包:train 86.4GB / val 2.62GB / test 2.86GB。
- **发布形态是 RIR 本体,不是渲染后音频**:README 指引用户下载 RIR 后,
  用仓库脚本 `data/data_tools/conv_ir_speaker_foa.py` 与 LibriSpeech
  干声语音卷积得到 FOA 语音。
- 卷积脚本查证:不重采样(采样率随干声,LibriSpeech 为 16kHz)、加载
  RIR 不归一化、卷积用全长(mode='full')不截断——即**下游音频的声学
  特性完全等于 RIR 的特性**。
- 仓库内**没有** SoundSpaces 渲染/数据生成代码(只有卷积与训练评测
  工具),无法从代码侧核对渲染配置。

## 三、公开包实测

**方法**:val 包(2.62GB)经 HTTP 字节范围请求取前 200MB,gzip/tar
流式解出前部 523 个文件(约 40 个样本目录,涵盖多个 HM3D 场景);对
全部 **161 条 RIR**(task1 单源 `ir.npy` 81 条 + task2 双源
`ir_male/female.npy` 80 条)做能量衰减分析。逐条证据存
`rir_audit_val_sample.csv`(与本报告同批交付);全部指标用 numpy 由
四通道能量和计算,Schroeder 逆积分求衰减曲线。

**格式**:每条 shape (4, ≈2090–2224) float64,即四通道 FOA、容器长度
中位 2146 采样(16kHz 口径 = 134 毫秒)。

**核心测量(161 条,16kHz 口径)**:

| 指标 | task1(n=81) | task2(n=80) | 说明 |
| --- | --- | --- | --- |
| 能量峰位(直达到达) | 中位 98 采样 ≈ 6.1ms | 同量级 | 即声音飞行约 2.1 米的时间,与"源距 1–4 米"吻合 |
| **峰后衰减 60dB 所需** | **中位 3 采样 ≈ 0.19ms** | **中位 4 采样 ≈ 0.25ms** | 全部 161 条在 2–4 采样之间,无一例外 |
| 到 −20 / −40 / −60dB 的位置 | 99 / 99 / 102(全体中位) | — | 三条线几乎同点 = 悬崖式衰减,不存在混响的缓坡 |
| 混响时间 T20/T30 | **不可计算** | 不可计算 | −5dB 与 −25dB 交叉点重合,无衰减坡可拟合 |
| 直达窗 / 其余能量比 | 中位 116.3dB | 中位 114.0dB | 直达之外的能量比直达低约 11 个数量级(可闻反射通常在 −5~20dB 区间) |
| 后半段能量占比 | ≤ 9×10⁻⁴⁸ % | 同 | 数值残渣级,等于零 |

**实测结论**:这些 RIR 是**带传播延迟与 FOA 方向编码的理想脉冲**——
只有直达声,无早期反射、无混响尾、无可测的衍射/透射成分。用它卷积出的
全部语音等效**消声室(自由场)渲染**:音频只携带方向与距离衰减信息,
不携带任何房间声学。若按 44.1kHz 口径解读,以上毫秒数还要再除以 2.76,
结论方向不变。

## 四、仍无法验证

1. **train/test 大包是否同分布**:只抽了 val 包前部(161 条);同一管线
   同一发布批次,合理推断同分布,但未实测(train 86GB 未下载)。
2. **造成纯直达的原因**:是渲染时把间接声路径关闭/反弹数设零,还是
   发布前的处理——仓库无生成代码,无法溯源。本报告只断言公开包现象,
   不推断作者意图。
3. **RIR 名义采样率**:无显式声明,16kHz 由"与 LibriSpeech 直接卷积、
   不重采样"推断;两种口径下结论一致。
4. 论文评测所用数据与公开包是否完全一致(常规假设一致,无法外部验证)。

## 五、对我们论文对比表的措辞建议(供 owner/导师定稿)

- 可写:"JAEGER 公开发布的 RIR 经实测为纯直达脉冲(峰值后 0.25ms 内
  衰减 60dB,直达/其余能量比中位 >110dB,混响时间不可测),其公开数据
  中的音频等效无回声渲染;本工作的双耳音频带真实房间混响。"
- 不写:任何"论文造假/夸大"类表述——其论文描述的是 SoundSpaces 管线
  能力,与公开包内容的差异原因未知(见第四栏)。
- 原内部记录"JAEGER 公开数据没有混响"**被实测支持**,且从"没有混响"
  加强为"没有任何房间声学(连早反射也没有)"。这使我们卖点中"房间声学
  (混响、遮挡)是真实仿真的"一项与最强对手的实测差异有了硬数字。

