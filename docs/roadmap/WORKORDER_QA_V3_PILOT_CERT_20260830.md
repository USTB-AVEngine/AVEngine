## 2. 阶段二:pilot 出题(对应排期第 3 步)

- **题型与量**:①⑦⑧⑨⑪⑯ 各 100 题级(⑨为修复后的重挖版,旧分只作
  参考);⑦只出"恰好一只在叫"主集子集,"都没叫/都在叫"两类锚点按对照
  身份单独成批。
- **每题产出**:MCQ 与开放两种形式(共享同一事实记录);答案推导链
  (逐步引用引擎记录文件);Gate A/B 孪生对按全案 2.3 干预表**逐题型**
  渲染(A 改音频选择事实、B 改承载答案的视觉事实);元数据含五基线
  声明、当次参数值、物理侧信号(ILD 峰值、DRR、事件间隔)。
- **负样本**:三态配额与"都不是"频率按 2.7;⑭"没人说过"型进音频充分
  拒答对照批。
- **审阅页**:按项目惯例平铺免点击、严格懒加载,答案与证据同屏。
- 验收:题量达标;答案键均衡;1.7 的约束检查全过;审阅页可开。

## 3. 阶段三:认证(对应排期第 4 步)

**认证单元 = 题型 × 评测形式 × 缺失模态**,逐格执行,矩阵一格不空:

- **条件**:完整音视频 / 只听(视频换黑帧)/ 只看(音轨静音)/ 纯文本
  (Gate C)。四条件同一批题、同一提示词模板。
- **探针三层**:物理特征分类器(1.6)/ 真正保留双声道的空间音频模型
  (SO 系配置)/ 通用全模态模型(Qwen3-Omni-30B,版本号写进结果
  manifest 并冻结)。评测前每条管线先过 1.1 双声道校验。
- **判定(单边非优势)**:该格单模态正确率的**单边上置信界** < 该格
  **条件基线 + `DELTA`** 才通过;条件基线按全案 2.7 逐题声明(⑦子集
  全 50%、①⑯只看 50%、⑧只听 50%……),数值题基线在**实际判分器**下
  Monte Carlo(固定种子,脚本入库)。统计单位 = 片段/孪生组,置信界用
  聚类 bootstrap 或分组置换;多格多探针做 **Holm 家族错误校正**;
  **任一探针任一层越线 → 该题型该形式降对照组**,不做多数表决。
- **Gate A/B**:孪生对逐题翻转核验(该翻必翻、该不变必不变,按题型
  干预表);翻转率与失败清单入报告。
- **oracle 重放**:每题推导链重放器——答案能由引擎记录机械重算,重算
  不一致的题作废并计数(这是可答性红线的第②层)。
- **人类可答性**:与容差带校准共用同一次人类实验(校准材料路线 A);
  完整音视频下人类正确率下置信界达阈值(阈值参数化,校准时定);强
  模型的完整输入成绩**只作难度诊断记录,不设门槛**。
- **报告**:逐格(题型×形式×模态×探针)准确率+置信界+判定;降级清单
  及原因;fresh 目录;检查点文档 `docs/roadmap/PILOT_CERT_<日期>.md`
  写实数(通过几格、降级几型、作废几题),不写"应该会"。
