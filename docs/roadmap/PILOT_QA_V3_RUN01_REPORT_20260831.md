## 3. 发现(按需要 owner 拍板的程度排序)

### 3.1 卡① 四扇区 MCQ 在当前场景结构性不可生产【要拍板】

证据链:
1. 设计约束"片尾锚定目标必须可见"⇒ 方位必须落在相机水平视锥
   ±52.5° 内;
2. 实测 40 个准入点的片尾真值方位全部落在 **[-31°, +8°]**(左右点数
   均衡 21:19,但右侧幅值最大只有 +8°)——固定审阅相机(yaw −145°)
   加走廊路线库的联合可行域就这么宽,与全案已知"±60°–105° 近乎空"
   同根;
3. 编排器上游复检"两只片尾不得同扇区"把 **40/40 全部拒出**:END_GAP
   ≥25° 与 45° 扇区宽可以共存(例如 −20° 和 +5° 同属"前"),四扇区
   选项在这个可行域里没有区分度。

本批处置:卡① MCQ 从编排移除,开放版(数值角度)保留——但其真值
范围同样只有 39° 跨度,±30° 容差下"报中位数"的乱猜策略不弱,认证时
条件基线会如实反映。

可选出路(都超出本工单,请拍板方向):
- 改选项空间:视锥内三带(左/中/右,边界与容差带对齐)——本批数据
  下右带仍近空,需要配合几何扩展;
- 加相机机位(新 M1 请求;视觉构图与遮挡需重新验证)或扩路线库
  (新弦需重走家具安全验证);
- 或接受卡①为窄角度数值题,叙事上不再用四扇区。

### 3.2 卡⑧ 时间带被锚定设计压缩【要拍板】

锚尾静默 ≥1.5 s + 四声叫 + 事件间隔约束 ⇒ 所有叫声被挤进前 3.2 s,
首叫实测最晚 2.58 s。原定 [0,5) 等宽四带的后两带**结构性为空**
(240 题分布 114/114/12/0)。本批已按实测可行域改为 0.65 s 等宽四带
([0,0.65/1.3/1.95/2.6)),分布大致均匀,参数显式注明占位。带域定版
(以及"等宽 vs 等频"的原则)请拍板。

### 3.3 外观真值轻度偏斜【已兜住,备案】

卡⑦ 55:41(黄毛:黑白,负样本另计)、卡⑨ 73:47。来源是逐点随机
首叫方 + 预筛选交互的波动,不是规则错误。五基线制的条件基线会如实
抬高(V-only 猜众数),不会造成假阳性认证;另给了外观均衡子集视图
(少数类全保、多数类确定性等量抽取)供对照。下一设计批可在装配器里
把首叫方按点序交替配平。

### 3.4 卡⑯ 等掩码通道【按工单顺序】

本批捕获产物只有 rgb + 帧记录,没有像素遮挡真值。卡⑯(两跳遮挡)
按工单 1.8 的掩码闸顺序:引擎侧掩码通道接入后,对本批(全部原始数据
已保留)补渲掩码、逐题像素复核卡①⑦ 的几何可见性判定,然后单独出
卡⑯ 题。
