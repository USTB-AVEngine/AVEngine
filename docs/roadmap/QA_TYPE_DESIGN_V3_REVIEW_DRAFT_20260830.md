## 第一部分 给审核者的背景

### 1.1 这个项目在做什么

我们在建一个投 **CVPR 2027** 的 benchmark(评测基准数据集),暂名
"Certified Spatial Audio-Visual QA"。一句话:在**物理仿真的室内场景**里,
模型看一段**第一人称视频**、听对应的**双耳音频**(binaural,模拟人两耳各自
听到的声音,左右耳的音量差与时间差携带方向信息),回答**跨模态问题**——用
一个模态的线索锁定目标("先叫的那只狗"),用另一个模态的内容提问("它是
什么毛色")。

场景、声源、运动轨迹全部出自自研仿真引擎(UE/SPEAR 与 habitat-sim 两条渲染
线;房间来自 apartment、kujiale、mp3d 三源)。每道题的答案不靠人工标注,由
引擎记录的真值(逐帧坐标、声音事件起止采样点、受控外观属性)机械推导。

**主叙事**:

> 在 360° 双耳听觉与有限视野第一人称视频下,考察**动态声源的错时跨模态
> 指代**;每个答案附带**引擎推导链**与**配对反事实证据**,可由脚本重跑核验。

### 1.2 CVPR 是什么、投稿环境什么样

- CVPR(IEEE/CVF Conference on Computer Vision and Pattern Recognition)是
  计算机视觉三大顶会之一(与 ICCV、ECCV 并列),近年每届投稿上万篇,接收率
  约 20%–25%。**CVPR 2027 的截稿日期官方尚未公布**;按 CVPR 2026 的惯例
  (2025 年 11 月 13 日截稿)估计在 2026 年 11 月中旬,距今约两个半月。
- benchmark/dataset 类论文的评审重点:①与既有 benchmark 的实质差异;
  ②数据与真值的质量可信度;③评测协议严密性(判分、防单模态捷径);
  ④基线覆盖现役最强模型且结论有信息量;⑤规模与多样性。
- 仿真数据会被问 sim-to-real,但空间音频子领域仿真是主流(SoundSpaces 系
  全是仿真),不是死穴。

### 1.3 竞争格局(2025–2026,已按事实核查修正)

| 对手 | 发表处 | 它做了什么 | 它没做什么(我们的空间) |
| --- | --- | --- | --- |
| **JAEGER**(SpatialSceneQA) | **ICML 2026 正式接收**(arXiv 2602.18527) | 6.1 万条仿真样本;Habitat + SoundSpaces 2.0,完整房间脉冲响应(反射/透射/衍射/空气吸收);**数值方位题**(输出方位角/仰角,中位角误差判分);**跨模态扬声器匹配**(哪个可见音箱发出目标语音,含重叠双源按性别指定) | 相机与声源**均静止**;四通道全景声(FOA)非双耳;**无视频轨迹、无动态听者、无任何时间锚题**;无逐题反事实认证 |
| **Hear you are** | CVPR 2026 | 360° 全景室内图 + SoundSpaces HRTF 双耳;有估角度/估距离题 | 静态全景图,无视频、无运动、无时间维 |
| **SAVVY** | 2025(arXiv 2506.05414) | **动态 3D 场景、移动物体**、时间锚与轨迹构建 | 真实视频、人工标注、无引擎真值、无反事实认证 |
| **DAVE** | NeurIPS 2025 | "每题双模态均必要"的诊断基准;时刻锚定句式范本 | 真实视频、人工标注、无空间数值维 |
| **BAT / SpatialSoundQA** | 2024 | 2.1 万条仿真双耳纯音频问答,8 扇区方位 | 无视频;方位粗扇区 |
| **AURA** | 2025 | 推理评测,AuraScore 拆事实一致性与推理有效性;**QA/选项/推理链由 GPT-4o 从自动 caption/transcript 生成** | 真值链由 LLM 生成,可能继承上游模型误差;无引擎状态背书 |
| **OmniVideoBench / TraceAV** | 2025–2026 | 长视频音视频多跳推理、幻觉鲁棒性 | 真实视频、人工标注、无空间数值题 |

**差异化怎么说**:单拎任何一项都不独家——数值方位 JAEGER 有、动态场景
SAVVY 有、双模态必要原则 DAVE 有、跨模态匹配 JAEGER 的 D/E 任务有。独家的
是**组合**:动态声源 + 动态第一人称听者 + 双耳 + 时间锚/错时指代 + 引擎
推导链与配对反事实。**时间维**是两个最强对手都没有的轴。对 AURA 的措辞:
其 gold reasoning 由 LLM 从自动生成的字幕/转写产生,可能继承上游误差;
我们的事实链由受控引擎状态机械推导、可重跑核验。

⚠ 待核实:内部记录曾说"JAEGER 公开数据无混响",与其论文 RIR 声明矛盾。
写论文对比表前翻它公开数据包实测(已列待办;当前措辞以"其论文声称"为准)。

### 1.5 走到今天的两轮教训

## 第二部分 设计正文

### 2.1 两线权威分工与统一目录(owner 拍板①)

- **QS 线**管题义定义、所需事实与可观察性判定、像素可见性/遮挡语义、原生
  证据与答案平衡门;v3 题卡的"这题在问什么、什么情况下可答"以 QS 协议
  口径为准。
- **T 线**管批量采样与挖矿、反事实孪生渲染、闸门与探针执行、训练集组装与
  模型评测。
- **v3 目录**:每张题卡标注与 QS 的关系(五分法)、生产线、证据级别
  (native pass / research batch / 已模型评测)。

### 2.2 两个评测形式,共享同一潜在事实记录

- 每道题先落一条**事实记录**(角度、事件窗、归属、外观值、台词等,含推导
  链);MCQ 与开放形式**各自声明**取哪个字段、问法、答案空间;**分别报告**
  随机基线、单模态基线与难度,不得用两版绝对分数互证同一能力结论。
- **MCQ 构造**:四选一;干扰项目标是**单模态条件下仍可行且均衡**。内容题
  (⑫⑬)的候选声音/台词须全部在当前片段出现且长度相近;方位/时刻题选项
  为互斥等宽带/扇区(边界写进题面);外观题候选取片段内实际出现值。选项
  分布按 split 内生成。含"以上都不对"的题,其为正确答案的频率单独披露。
- **开放判分三级**(能走前面的不走后面的):
  1. **数值容差带**:方位角用**环形角距离**;±15°/±30° 为 owner 批准占位
     值、尚未由 DoA 模型或人类误差分布校准,终稿前校准;同报 MAE、中位角
     误差、success@{15°,30°,45°}。时刻 ±0.3s/±1.0s,**同报均匀乱猜的期望
     得分基线**。计数全对才得分。
  2. **闭集枚举核对**:归一到枚举值再精确匹配;不做裸子串匹配;检测到
     否定词或多枚举冲突判 invalid。
  3. **裁判模型**:仅限自由描述;固定版本、公开规则与结构化原始评分;与
     人工双盲抽样验证一致性;定位**次级诊断**。
- **拒答判定(R2.1 收紧)**:对**可回答的负样本题**(如⑪:答案确定是
  "来自画外"),主准确率只认正确断言;**含混拒答("无法判断")在主准确率
  中记零分,不给部分分**——否则永久拒答的策略会获利。模型的弃答率
  (abstention rate)作为独立行为指标单独报告,不进主分。
- 推理题(⑯):**最终答案分与解释质量分分开报告**,解释分不回改答案分。

### 2.3 防线与认证

**防线一:同种双实例**(在产):两只同物种、受控外观区分、同族叫声。

**防线二:错时指代(锚定时刻 ≠ 提问时刻)——必要而不充分**。
**适用范围声明(R2.1)**:下述**错时准入六条件只适用于错时族**(①、④原版、
⑤R、⑥R);非错时的主集候选(⑦⑧⑨⑪⑫⑬⑭⑮a⑯)各有其结构检查(写在各自
题卡),再统一过批级认证与 AV 可答性红线。

**错时准入六条件**(R2.1 从五条扩为六条,主集候选须全过):

1. 锚定事件之后,目标不再产生可识别音频(不叫、无脚步声、混响尾不覆盖
   提问窗);
2. **锚定时刻可绑定(R2.1 新增)**:锚定事件发生时,声音必须能绑定到视觉
   实例——目标此刻可见,或属于明确设计的"画外→入画"路径;候选实例间的
   方位角分离足够;真实双声道输入中方向线索可解析。防止"单模态都随机、
   完整音视频也不知道是谁"的不可答题在统计上蒙混过关;
3. 发声方向、声源槽位、轨迹模板不能统计性预测提问时刻答案(按可听特征
   分桶后答案仍均衡);
4. 发声期间的运动不足以外推提问时刻状态(轨迹须含停走转折);
5. 通过物理特征分类器探针(见防线三);
6. 提问时刻目标在画面中可观察(接既有像素可见性管线)。

**完整 AV 可答性红线(R2.1 新增,适用于全部主集候选)**:每个题型须证明
"给全音视频时确实答得出"——人类抽验与强 AV 模型在完整输入下的正确率
**下置信界达到预定水平**(具体阈值随容差带校准一起定),达不到的题型不进
主集,不能只靠"单模态答不出"入选。排期第 4 步的"人类抽验"即执行此红线,
不通过即拦下。

**Gate B 的按题型干预定义(R2.1 重写)**:名称保留闸门 A/B,但 Gate B 不再
统一等于"换外观孪生"。定义:**Gate B = 只改变该题真正承载答案的视觉事实
变量,保持音频锚不变,答案必须翻转**。各主集候选的干预变量:

| 题 | Gate B 干预的视觉事实 |
| --- | --- |
| ⑨⑫⑬⑭ | 外观/衣色属性(经典属性孪生) |
| ① | 锚定事件后的未来轨迹(片尾位置换位) |
| ④原版/⑤R | 提问窗内的距离关系/位移方向 |
| ⑥R | 静默段的运动状态(动↔静) |
| ⑦ | 锚定时刻的发声归属对应的外观(叫声调换) |
| ⑯ | 片尾可见性/遮挡状态(挡↔不挡) |
| ⑪ | 发声实例的在场性(画外源↔画内源) |

Gate A(换音频锚,答案翻转)同理按题型声明干预变量(如①换第二声归属)。

**防线三:批级认证的统计方案(R2.1 修订)**:

- **判定逻辑:单边非优势检验**(名称按 codex 意见收紧,不再称"等效性
  检验"):预先声明容许捷径幅度 δ(建议条件基线+5 个百分点,数值待
  owner/统计侧复核);对每个题型×单模态条件,计算单模态正确率的**单边上
  置信界**,上界低于"条件基线+δ"才发"单模态不可答"的批级认证;越线即降级
  对照组。条件基线按该题型真实答案先验与选项可排除性计算,不一律用均匀
  随机。
- **统计单位是片段/孪生组**;区间用聚类 bootstrap 或分组置换。
- **多重检验用家族错误控制(R2.1 修订)**:Holm/Bonferroni 或 cluster
  max-stat,不用 BH-FDR——FDR 允许一定比例假阳性,而"发认证"要防的恰是
  错误放行。**任一探针、任一层越线即降级**(取最严,不做多数表决)。
- **样本量先行**:按 δ 与目标功效算每题型所需片段数,不够补采样,不硬发
  认证。
- **探针三层**:①物理特征分类器(响度 RMS 趋势、直达混响比 DRR、双耳
  强度差/时间差、事件密度、声纹相似度)——**oracle 条款(R2.1 新增):
  特征只能从最终向模型发布的音频文件计算,禁止使用干声素材、真实房间脉冲
  响应或引擎隐藏字段**,否则测到的是引擎侧信息泄漏,不是模型可利用的侧
  信道;②真正保留双声道的空间音频模型(SO 系/BAT 类);③通用全模态模型
  (版本冻结)。评测前先过**双声道通道校验**。
- **探针在未参与题型设计的 held-out split 上跑**;split 隔离:视觉片段、
  孪生组、房间、轨迹、说话人、台词。
- **逐题证据与批级认证分离**:逐题保存结构性反事实(Gate A/B 翻转记录)
  与推导链;模型探针只做批级捷径检测,不冒充逐题证书。

**质检档案**:每道入库题自带机器可重跑档案——①答案推导链;②Gate A/B
翻转记录(按题型干预定义);③探针与物理分类器原始输出。"模态必要性"是
题型批级统计结论,不宣传为逐题证明。论文措辞:machine-verifiable question
audit。

### 2.5 题卡(R2.1 修订;每张含体系标注)

> 场景通用:两只同种(黑白毛边牧/黄毛拉布拉多)或两人(蓝/绿/酒红上衣);
> 发声时刻随机、每集≥3 声;轨迹含停走转折。英文句式照 DAVE 范本。

**题① 错时方位(卖点)【主集候选(错时族)】**
- MCQ(R2.1 修扇区):四等分**前/右/后/左**,边界写进题面(前=[−45°,45°),
  右=[45°,135°),后=[135°,180°]∪(−180°,−135°),左=[−135°,−45°));
  "发出第二声叫的那只狗,到视频结束时在你的哪个方向?" → 真值 −85° 落
  **左区**,答案"左"。(如需更细粒度用八扇区,与开放版容差带对齐后定。)
- 开放:"……视频结束时相对你的朝向大约多少度?(右为正)" → −85°;环形角
  距离,±15°/±30°(占位待校准),另报 MAE/中位/成功率@多阈值。
- 双模态论证:第二声归属只有音频知道;片尾它不叫,方向只能看。
- 准入:错时六条件(锚定时刻两只须可绑定:锚时目标可见或走画外→入画
  设计路径、方位分离达标;片尾可见性走像素管线;发声方向/槽位/轨迹与
  答案条件均衡)。
- Gate A:换第二声归属,答案翻转;Gate B:换锚后轨迹(片尾位置对调),
  答案翻转。
- 体系:全新题义;生产:T 线新增错时采样器;证据:设计稿。依赖:侧向
  方位补桶;像素可见性接入(管线已有)。

**题② 发声时刻方位【对照组(音频充分)】**
- 同题①但问发声那一刻;光听可答,作纯双耳定向测量,与题①成对量化
  "错时"增加的难度。体系:全新;证据:设计稿。

**题③ 左右【对照组(音频充分)】**
- "第一声叫来自画面的左侧还是右侧?"在产。前置:评测管线过双声道校验
  (旧分数带管线混淆脚注)。体系:复用 QS-004 完整题义(native pass 526);
  证据:已模型评测。

**题④R 第 2.0 秒谁更近【对照组(视觉充分)】**
- 视觉对照重定义为给定时刻("第 2.0 秒时谁更近")。原"第一声时谁更近"转
  主集候选存档,准入:两只距离排序在视频内交换过 + 错时六条件。
- 体系:全新;证据:需按新定义重挖重测。

**题⑤ 靠近还是远离【原形态→对照组;⑤R 错时版主集候选】(拍板②)**
- 原形态(发声期间)的响度趋势、DRR 变化、动态双耳差光听可判 → 声学运动
  对照组。
- ⑤R:"它叫停之后继续走,片尾比叫的时候离你更近了还是更远了?"准入:
  六条件(特别是锚后无脚步声)。Gate B:换提问窗内位移方向。
- 体系:全新;证据:设计稿。

**题⑥ 第二声期间它在动吗【原形态→对照组;⑥R 错时版主集候选】(拍板②)**
- 原形态有声学运动侧信道 → 对照组(=QS-006 所指题义,QS 侧同步标注)。
- ⑥R:"第二声叫**结束之后**,发出它的那只动了没有?"(提问窗在锚后静默
  段)。准入:六条件。Gate B:换静默段运动状态(动↔静)。
- 体系:原形态复用 QS-006 完整题义;⑥R 全新;证据:原形态已模型评测
  (失效史),⑥R 设计稿。

**题⑦ 第 t 秒谁在叫【主集候选】**
- MCQ:"第 3.0 秒(视频时钟)正在叫的是哪只?"黑白毛/黄毛/都在叫/都没叫。
- 开放:同题干,闭集归一;"都没叫"负样本按配额混入。

**题⑧ 它第一次叫是第几秒【主集候选】**

**题⑨ 先发声的是哪只【主集候选·最接近通过】**

**题⑪ 谁发声/都不是【主集候选,R2.1 重修】**
- **场景(R2.1 修实例数矛盾)**:画面里**三只狗**可见(黑白毛、黄毛、沙发
  上第三只),都没叫;叫声来自**画外第四只狗**。选项:黑白毛/黄毛/沙发上
  那只/都不是(来自画外)→ 都不是。
- **matched-DoA 构造(R2.1 新增,封"方向在视野外"捷径)**:画外声源的
  方位角不能明显落在相机视野角度范围之外——否则光听方向就知道"画面里
  不可能有"。构造要求:画外源方位落在视野内某可见实例的邻近方向(声源
  在该方向上但本体被墙/门遮挡或在门外),使"都不是"必须靠"听到的方向上
  那只没有发声动作/方向对应处无实例"的视听比对得出。负样本三态(静音
  在场/出画发声/多实例单发声)同一构造原则。
- **拒答判分(R2.1 收紧)**:这是可回答的负样本(答案确定是"画外"),
  开放版主准确率只认正确断言;"无法判断"记零分;弃答率单独报告。
- 体系:复用 QS-001 事实字段 + QS-008 答案空间(非完整题义);生产:T 线+
  QS 可见性判定;证据:QS 侧原生通过,批量版设计稿。

- 开放:闭集归一(声音种类是登记字段)。
- Gate A:调换目标与非目标的声音,答案翻转;Gate B:外观孪生。
- 体系:复用 QS-002 事实字段(反向);生产:T 线多声部编排采样;证据:
  设计稿。

**题⑬ 蓝上衣的人说了什么【主集候选(素材线依赖),R2.1 修唯一性】**

  非目标 3 句(绿衣人两句+画外一句,或类似组合),与 QS-012"目标实例唯一
  受控台词"的口径对齐。多句目标一律拒出(或改用事件锚"第 2 秒时蓝衣人
  说了什么"另立变体)。
- MCQ:四条候选台词都在片段音轨中出现、长度相近 → 唯一正确项为目标那句。

- 体系:复用 QS-012 完整题义(已有含逐字台词的 native pass);证据:QS

**题⑭ 说"过来"的人穿什么【主集候选,R2.1 拆负样本】**

**题⑮ 数量【R2.1 拆分定性】**

  绑定;价值在"音频必要"硬证据。
- **⑮b"一共听到几声叫?"——纯音频题(R2.1 移对照组)**:数事件光听即可,

- 体系:全新;证据:v1 有同族实测。

**题⑯ 两跳遮挡推理【主集候选·小配额亮点】**
- MCQ:"最先叫的那只,视频结束时处于什么状态?"清晰可见/可见但部分遮挡/

  Gate B 干预变量是遮挡状态而非外观。
- 体系:组合 QS-003(指代步)+ **QS-008 答案空间(非完整题义)**+
