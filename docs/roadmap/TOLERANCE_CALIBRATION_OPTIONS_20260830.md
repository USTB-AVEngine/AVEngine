# 容差带校准决策材料(20260830)

> **这份文档是什么**:全案 v3 的数值题计分带——角度 ±15°(满分)/±30°(半分)
> 与时刻 ±0.3s/±1.0s——目前都是 owner 批准的**占位值,尚未校准**。本材料给
> 出两条校准路线的具体做法、样本、算法、输出与优缺点,供 owner/导师选路。
> **本材料只给建议,不把占位值写成最终结论**;校准完成前,一切引用这些
> 数值的地方(判分器、准入约束、基线模拟)都以显式参数形式引用。

## 0. 计分带在体系里管什么(为什么它是 pilot 前的闸)

计分带不只是判分参数,它被四处引用,定了它才能开工:

1. **开放版数值题判分**:满分带 / 半分带(题①②⑧,以及押后的位移数值版);
2. **题①的两条准入约束**直接以带宽为单位:目标锚后位移 > 满分带宽;
   两只片尾角度的环形距离 > 2×半分带宽(防猜错者蹭带);
3. **题⑧的最小分离**:两只首叫间隔 > 半分带宽(占位即 1.0 秒);
4. **五基线的 Monte Carlo**在实际评分器下算期望分——带宽变,基线变,
   认证阈值跟着变。

所以执行顺序上,校准排在排期第 2 步(基础设施)和第 3 步(pilot 出题)
之间:先有带宽,才能出合规的数值题和算对基线。

## 路线 A:人类小样本校准

**做法**:从 pilot 小批里抽数值题(题①片尾方位、题⑧首叫时刻两类为主,
每类 30–50 题),请 3–5 个人(组内同学即可,不需要听音专家)在**完整
音视频**条件下作答开放版,记录数值答案。需要先做一个简易作答页面
(视频播放 + 角度拨盘/时间输入,一天以内的工程量)。

**计算**:每人每题的误差 = 环形角距离(角度题)或绝对时差(时刻题);
汇总得到人类误差分布;分位数的置信区间用自助法(bootstrap)估计。

**带宽定法(建议规则)**:满分带 = 人类误差分布的 **P75**(四分之三的
人类作答落在带内);半分带 = **P95**。逻辑:人在完整音视频下能达到的
精度,就是要求模型达到的合理精度;比人类精度还窄的带宽会把题目变成
假难(连人都过不了的题测不出模型能力,还会拉低"人类可答性红线")。

**输出指标**:人类误差直方图;P50/P75/P95 及其置信区间;按题类分列
(片尾方位与首叫时刻分开定带);按方位桶分层(正前方 vs 侧向,人类
双耳定位在侧向精度更低,分层结果决定要不要按方位分带)。

**样本量**:5 人 × 40 题/类 = 每类 200 个数据点,P75 的估计已稳,P95
的置信区间偏宽(尾部数据少)——若 P95 抖动大,加题到 60–80 或加 1–2 人。

**优点**:
- **与"人类可答性红线"共用同一次实验**——红线要求人类在完整输入下的
  正确率下界达标,这批作答数据一鱼两吃,既出红线数字又出带宽;
- 审稿叙事最硬:"带宽 = 人类 P75/P95"一句话讲得通;
- **时刻带只有这条路线可用**(见路线 B 缺点)。

**缺点**:要组织人力(每人约 1.5 小时);作答界面要先做;误差里混入
界面操作误差(拨盘精度、拖动进度条的手误)——界面要做校准试题剔除
明显操作失误;人少时尾部分位数抖。

## 路线 B:专用模型误差分布校准

**做法**:拿专用的声源方位估计模型(BAT 类,或我们 SO 系里带方位输出的
配置)在 pilot 音频(真双声道)上跑逐事件方位估计,与引擎真值比对,取
误差分布。时刻侧对应做法是声音事件检测模型的起始点(onset)误差。

**计算**:逐事件环形角误差分布;按方位桶(正前/侧向)、距离桶、混响
强弱分层。

**带宽定法(建议规则)**:满分带 = 专用模型误差的 P50–P75;半分带 =
P90。逻辑:专用模型的精度代表"这个信息在音频里物理上可恢复到什么程度"
——它是**上界证据**(音频里根本恢复不到 ±10°,就不该要求 ±10°)。

**输出指标**:专用模型误差分布与分层表;顺带产出一个副产品——按方位桶
分层的误差能反向验证我们数据的双耳线索质量(侧向误差应显著小于正前方,
不是的话说明双声道渲染或方位分布有问题)。

**优点**:全自动、不占人力、样本量随便加;能按物理条件分层,给"要不要
分方位定带"提供依据。

**缺点**:
- 专用模型精度 ≠ 人类感知精度,更 ≠ 全模态模型该被要求的精度——拿它
  直接定带宽通常**过严**;
- **时刻带不能用这条路线**:onset 检测模型的精度在 ±0.01 秒量级,拿它
  定时刻带会得出荒谬的窄带(±0.05s 之类),而时刻题考的是"绑定对了没",
  不是信号处理精度;
- 依赖 DoA 估计管线适配(输入格式、事件切窗),约 1–2 天工程。

## 建议(供拍板,非结论)

1. **主路线 A,路线 B 做辅助验证**。理由:A 与人类可答性红线共用实验
   (反正红线是必做的);时刻带只有 A 能定;B 全自动,顺手跑一遍作
   交叉验证——若专用模型 P75 远小于人类 P75,说明音频信息充足、人是
   瓶颈,用人类值定带合理;若两者接近,说明带宽已贴物理极限,双保险。
2. **角度带与时刻带分别校准**,不追求形式统一;是否按方位分带(正前
   窄带、侧向宽带)看 A/B 两路的分层结果再定,第一版建议全局一条带,
   避免判分器复杂化。
3. **①⑧的最小分离条件写成参数公式**,不写死数:片尾角距 > 2×半分带宽;
   首叫间隔 > 半分带宽;锚后位移 > 满分带宽。校准值一落地,这些约束
   自动跟着变。
4. 校准完成前,±15°/±30° 与 ±0.3s/±1.0s 继续以占位身份存在于文档,
   判分器与采样器以显式参数引用(与 pilot 工单的"未决参数显式化"要求
   一致)。
