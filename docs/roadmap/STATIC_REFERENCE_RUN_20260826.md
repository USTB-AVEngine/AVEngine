## 修掉的两个真实集成 bug

两个都是**第一次真跑**才暴露的：两边的单测互相把对方桩掉了，所以它们从没在一次运行里见过面。
补丁脚本在 `examples/assets/source_profiles_mirror/spear_patches/`（SPEAR 仓提交不了）。

1. **准入运行器永远无法校验真实的水密清单。** 水密工具总会在 `attribute_input` 里多写一个
   `same_as_geometry_input`，而 `validate_file_record` 要求字段集精确相等。
   修法是**校验那个标志**（静态物必须为 true）再剥掉它去校验文件记录 —— 比原意更严。
   单测的桩也一起改成和真工具一致，14 条全绿。
2. **定型工具的受保护字段里有一个在 glTF 往返下不守恒的量。** `vertex_count` 会因为
   导出时在 UV/法线接缝处裂点而变化（实测 37293 → 37353，三角面数 60000 不变）。
   改成按位置焊接后的顶点数，实测 30002 → 30002。

## 还开着的口子

1. **静态链路没有任何一步校平。** 定型只做偏航。九个重建的长主轴离理想方向差
   5.7°–22.5°（均值约 13°）。后果可量化：后仰 11.7° 的书架箱按包围盒高度缩放到 33 cm，
   真实柜高只有约 29 cm（12% 误差），而且在场景里肉眼可见地歪。
   动物那条链有 `blender_level_generated_animal_support_plane.py`，但它要骨架和四只脚，
   刚性物体用不了。**要么补一个刚性物体的校平算子（双权威：支承平面 + 主面板对齐），
   要么改 pose guard 用平视相机**（倾斜来自"略高于视平线的三四分之一视角"）。
   这条对 Codex 那 26 个资产同样成立。
2. **两个 profile 的方法修订还没跑**（书架箱 v2 单元数、电视 v2 可见出声口），
   第二批的 inputs 和 preflight 已经建好在 `tmp/audio_playback_statics_v2/`，
   只差跑文生图。落地箱三个全灭（幻觉物件 / 柜体裂开 / 垂线），智能音箱两个全灭
   （33.7% 碎片 / 歪 18.9°），这两类都要重来。
3. **评审渲图过曝、材质带金属度**，黑色音箱渲出来是银色。饰面属性判不了。
   贴图本身是忠的（实测 albedo 均值区分度很好），要么改渲染曝光，要么量图集。
