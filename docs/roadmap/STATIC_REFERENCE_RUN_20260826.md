## 修掉的两个真实集成 bug

两个都是**第一次真跑**才暴露的：两边的单测互相把对方桩掉了，所以它们从没在一次运行里见过面。
补丁脚本在 `examples/assets/source_profiles_mirror/spear_patches/`（SPEAR 仓提交不了）。

1. **准入运行器永远无法校验真实的水密清单。** 水密工具总会在 `attribute_input` 里多写一个
   `same_as_geometry_input`，而 `validate_file_record` 要求字段集精确相等。
   修法是**校验那个标志**（静态物必须为 true）再剥掉它去校验文件记录 —— 比原意更严。
   单测的桩也一起改成和真工具一致，14 条全绿。
2. **定型工具的受保护字段里有一个在 glTF 往返下不守恒的量。** `vertex_count` 会因为
   导出时在 UV/法线接缝处裂点而变化（实测 37293 → 37353，三角面数 60000 不变）。
   改成按位置焊接后的顶点数，实测 30002 → 30002。

   **回音壁那 40% 是这批里最贵的一笔**：扁平长条歪 14–18° 时包围盒高度几乎翻倍，
   所以按 7 cm 高定型之后长度只剩 20–23 cm。**校平之后同一个网格会长到约 33–37 cm。**

   工具用两个互相独立的权威（最大近水平面板 + 最低共面底板），
   **两者都从物体自己的平面读出，不假设物体已经站直**。
   闭环验证（把修正量施加上去再量）：分歧 <1.3° 的资产修正后残余 0.06°–0.63°，
   分歧 3.0° 的那个修正后仍差 11° ——**所以分歧度就是可靠性信号**，默认容差按此定为 1.5°。
   另有一条"合理性上界"（30°）：两个权威**会**同时选中同一个错误面并高度一致地给出
   42° 这种答案，一致性检查抓不住，只有输入契约（pose guard 要求物体稳定放置）能抓住。

### 平视相机实验（已跑完，结论：方案①不够）

三个方案里最便宜的一个是"改 pose guard 用平视相机"——如果倾斜是从输入视角继承的，
改一句话就免费修好整族，不用动链路也不用升 schema。**这条已经用实验判掉了。**

给智能音箱和回音壁写了 v3 方法修订（相机正好平视、位于物体自身中部高度、绝不俯视，
负向堵 high angle / looking down / dutch angle），重跑 6 个候选。
对照组是同一把尺子量的**原始网格**（不是定型后的，两者读数差 <0.2°，确认定型不改变倾角）：

| 物体 | v1 pose guard | v3 平视相机 | 变化 |
|---|---|---|---|
| 智能音箱 | 15.26 / 17.53 / 18.63 / 17.13（均值 **17.14°**） | 17.19 / 12.49 / 12.96（均值 **14.21°**） | **−2.9°（降 17%）** |
| 回音壁 | 17.19 / 14.21（均值 **15.70°**） | 8.68 / 9.67（均值 **9.18°**） | **−6.5°（降 41%）** |

**回音壁那一行本来还有第三个读数 0.45°，是假象，已剔除。** 那个网格顶视图里融进了
一整块幻觉出来的电器面板（带旋钮和风口），509 个连通分量、6.8% 碎片、包围盒被撑大 3.3%——
**工具量的是那块平板完美水平的平面，不是音箱。** 它已在 3D 评审中被拒。
教训：**倾角读数的可信度不超过它下面那个网格**，所以人眼看渲图必须在量之前。
（我一度把这个 0.45° 当成"平视相机能做到完美"的证据，是错的。）

**结论有三层**：

1. **相机俯角是原因之一，但不是全部。** 回音壁降了 41%，智能音箱只降了 17%，
   而且**两者都没有降到可用**（最好的一个仍有 8.68°）。
2. **而且不稳定。** 同一个 profile 下 8.68° 到 17.19° 都有。
3. **形状决定收益**：宽扁物体（回音壁、电视）受益最大且本来就最正，
   细高物体（圆柱）几乎不改善。合理——宽扁物体的轮廓强约束了朝向，
   圆柱接近旋转对称，重建没有可依附的东西。

所以 **①要留（免费且有效，尤其对宽扁物体），但必须配 ②**。
我的建议收窄为 **①+②**：保留平视相机的 pose guard，
再把朝向证据从只有 yaw 扩成 yaw+pitch+roll 让定型工具应用——
度量这一侧已经现成，②只是把数字接进去。

报告：`/data/avengine_external/review/static_upright_level_camera_20260826.json`。
