# QA 题型体系 v2 草案：跨模态指代矩阵（20260823）

> 状态：**设计草案，供 owner/导师迭代**，不是最终题型，不构成 dataset admission。
> 输入：owner 的 benchmark 调研报告（MUSIC-AVQA / DAVE / FortisAVQA / BAT /
> SAVVY / AVHBench / AV-Odyssey / OmniVideoBench 等 16 篇）、2027CVPR.md
> 0713 期望 QA 与 0810 导师讨论、v1 QA 评估报告
> （DATA_EVAL_20260823_UNIQUE1000_QA.md）的缺陷清单。
> 核心机制一句话：**指代用一个模态，提问用另一个模态；指代的可解性由
> 受控实例属性保证**。

## 0. 设计公理（从 v1 教训与调研直接推出）

1. **指代必须有歧义压力**：场景内同物种/同类别 ≥2 个实例，仅靠受控属性
   （毛色深浅/体型/上衣颜色）或声音特征可区分。v1 的死穴（问句点名物种
   +物种唯一）在源头禁止：**禁止在问句中出现场景内唯一存在的类别名**，
   除非该题型故意考存在性。
2. **每题过单模态可答性闸门**（调研报告 §6.4 的流程引擎化）：
   - V-only 探针（规则/几何真值近似 + 抽样人工）能答对 → 删或改；
   - A-only 探针能答对 → 归入"音频充分"对照组或改；
   - 双探针都答不对、AV 才能答 → 主集（对应 DAVE 的核心原则）。
3. **两套 setting 同源**：每题先写 canonical answer（自由文本/数值），
   再机械选项化成 MCQ。MCQ 用于第一版评测；reasoning 版直接用 canonical
   answer + 推理轨迹标注（OmniVideoBench 式），不另出题。
4. **选项工程**：≥4 选项、干扰项必须在数据集中真实出现过（防 Q-ATTR 式
   "干扰项永不为真"）；答案位置均匀（防 A/B 位置先验）；同题干做同义
   改写 ≥2 版（FortisAVQA 第一阶段）。
5. **负样本是一等公民**（AVHBench/调研 §6.4 第 4 步）：静音在场、出画
   发声、多实例单发声，各题型按固定配额混入，含"以上都不对/无法判断"
   选项的 refusal 落点。
6. **真值全部由引擎签发**：DoA/距离/遮挡比/事件窗/属性都来自 manifest
   与 fact table，不靠人工标注；人工只做听审与可答性抽验。

## 1. 指代 × 提问矩阵（骨架）

指代维（怎么锁定目标实例）：
- **R-V**：外观属性指代（"穿绿色上衣的女人""较大的浅色金毛"）
- **R-A**：声音指代（"刚才叫了两声的那只狗""说'过来'的人"）
- **R-S**：空间指代（"圆桌左侧的那只狗"——本身可由任一模态解析）
- **R-T**：时间锚指代（"第二声猫叫时…"——锚点几乎总在音频）

提问维（问目标的什么）：
- **Q-V**：外观/动作（毛色、在走还是站、在做什么）
- **Q-A**：声音内容/属性（说了什么、叫了几声、哪种叫声）
- **Q-S**：空间（方位、距离、相对家具位置、DoA 数值）
- **Q-T**：时序（先后、期间、间隔）
- **Q-N**：数量（实例数、事件数）

**论文主集 = 反对角线格子**（指代与提问不同模态）：R-V→Q-A、R-A→Q-V、
R-A→Q-S、R-T→Q-V/Q-S。同模态格子（R-V→Q-V 等）保留小配额作对照组，
用来量化"跨模态税"（模型在同模态题和跨模态题上的落差本身就是结果）。

## 3. 认证协议（升级 axis1 → 三闸门）

v1 的 axis1 只验"音频换了答案变不变"，查不出"不给音频能不能答"。v2：

1. **闸门 A（音频必要）**：route-swap 孪生答案翻转（现成 axis1 机制）；
2. **闸门 B（视觉必要）**：属性 twin——同轨迹换毛色/衣色资产渲染，答案
   必须翻转（引擎能做，v1 没做；对应 P2' 属性干扰对）；
3. **闸门 C（文本不充分）**：question-only 盲猜 ≤ chance + ε（用现成
   text_only 管线批量跑）。
   三闸全过 → certified 主集；过 A+C 不过 B → 音频充分对照组；以此类推
   打标签，论文可按认证等级分层报数（AURA 式解耦评估）。

## 4. 两套 setting 的落法

- **Setting-1 MCQ**：4 选项 + 均匀位置 + 真实干扰项 + refusal 选项按配
  额出现。指标：acc、按题类 macro、AV−V/AV−A 差值、认证层分层 acc。
- **Setting-2 Reasoning**：同题 canonical answer（自由文本/数值带），
  数值题按计分带打分；抽样配推理轨迹标注（先 10%，够画图就行）。
  两套共享题干与真值，成本只多一次选项化。
