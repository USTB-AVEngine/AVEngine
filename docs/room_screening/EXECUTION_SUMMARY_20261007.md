# HM3D 房间面积与初筛运行摘要（交付版 V4，2026-10-07）

本摘要覆盖已下载的 181 栋 HM3D 场景中的审核队列。队列含 1,382 个唯一对象，来自 180 栋有审核对象的场景；另 1 栋无审核队列对象。派生建议不修改正式 verdict。此处“交付版 V4”指最终筛选批次，不是早期作废的 AABB 扩张试算 V4。

## 方法与校准

- 主面积为同层语义地面水平投影并集，扣除已识别阻挡物占地并集，并纳入经地面几何和场景结构确认的漏区补片。
- 1.80 m 高、0.20 m 半径 Habitat 探针只作碰撞、遗漏和连通核验；采样格面积不直接加减主面积。
- 参考 AABB 不等于物理墙线。框外补片须结合楼层、同层地面、家具/桌面、墙体、门洞及空间主体归属判定。
- 两批共 94 条负责人范围/场景与文字反馈进入计算或筛选校准；原始文字和逐房输出不随仓库提交。
- 1,379 条面积可计算，3 条楼层/源几何映射失败并标为不可评估；正式 verdict 改动数为 0。

## 初筛分流

| 状态 | 数量 | 说明 |
|---|---:|---|
| 暂列可用候选 | 900 | 未触发当前面积、形状或场景筛选条件，不是正式“用” verdict。 |
| 舍弃候选 | 282 | 项目面积下限、形状条件或直接场景证据触发。 |
| 裁剪复核候选 | 178 | 主面积达到 50 m²；须按真实空间边界进一步判断。 |
| 范围敏感 | 19 | 5 条可能影响 10 m²判断，14 条可能影响 50 m²复核；保留待定状态。 |
| 不可评估 | 3 | 楼层或源几何映射失败，不按 0 m²处理。 |

形状规则联合考虑连通块、最大块占比、长短轴比和局部宽度，并先排除扫描/范围缺口。楼梯/走廊只在图像和结构证据确认其占主导且没有独立房间主体时才列为舍弃候选；单有语义类别标签不足。未冻结任务必需家具清单前，不因未见家具单独淘汰。50 m²只触发裁剪复核，不自动切块。

## 结果边界

“暂列可用/舍弃/裁剪”是本项目的派生建议，不是正式审核结论，也不证明真实人物移动、声学、摄像机或具体下游任务适用。19 条范围敏感及 3 条不可评估记录不会阻断其他对象的初筛交付，也不要求负责人逐条重审。逐房表、图像、视频和原始意见保留在受限工作区；仓库仅含去标识规则和汇总。
