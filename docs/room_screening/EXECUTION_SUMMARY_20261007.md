# HM3D 房间面积与初筛运行摘要（2026-10-07）

本摘要仅记录汇总统计和方法状态；逐房表、场景图像、视频和负责人原始审核意见留在受限工作区，不随代码提交。

## 覆盖范围与方法

- 目标清单为 181 栋已下载 HM3D 场景；其中 180 栋有审核对象，共 1,382 条房间记录；另 1 栋没有审核队列对象。
- 主面积以同层语义地面水平投影并集减去已识别阻挡物投影并集为基线。经核对的框内补片和同层框外地面多边形可并入；探针只发现漏区和核验碰撞路径，不把探针网格面积加到主面积。
- 探针配置为高 1.80 m、半径 0.20 m、水平采样步长 0.10 m。碰撞路径只说明几何净空；不表示房间归属或声音互通。
- 两批人工反馈已用于校准结果：早期 67 条范围/场景审核意见用于几何补片归属与场景类型判断，随后 27 条反馈用于更新初筛意见和回归标记。没有修改原始场景数据或正式审核 verdict。

## 初筛建议（非正式审核结论）

| 建议 | 数量 |
|---|---:|
| 暂列可用候选 | 915 |
| 舍弃候选 | 54 |
| 裁剪候选（主面积达到 50 m²复核线） | 181 |
| 范围待核 | 229 |
| 不可评估 | 3 |

10 m²为本项目指定的候选筛选下限；50 m²为裁剪复核线。裁剪建议不等于已经切分。楼梯/走廊主导且没有房间主体、面积和形状规则分别记录；颜色或语义标签单独出现不触发淘汰。范围待核和不可评估对象不自动判为可用或舍弃。

## 连接检查及局限

全量逐组件检查得到 7,265 个框外同层候选组件：702 个最近点直线路径通过碰撞检查，其真实地面多边形并入；2,168 个该直线路径受阻，未并入，但没有穷举所有绕行路径；4,395 个因连续地面几何缺口无法核实。剩余 229 条可影响 10 m²结论的记录作为范围待核项，尚未形成最终归属判断；它们不会因此自动判为可用或舍弃，也不需要负责人逐条审核。

本结果是几何候选初筛，不是墙内净面积真值、Navmesh 全覆盖证明、真实人物任务可用性或声学连通证明。正式 verdict 保持原样。
