## 渲染效率记录

- 管线已拆分为 UE/GPU render queue 与 CPU evidence/finalize queue；GPU 槽位不再等待 Matplotlib 和 FFmpeg。
- 原始成年男 12 秒 canary 单任务总耗时 2 分 14 秒，其中 UE 阶段约 54.5 秒。
- 其余 5 个任务使用 4 个 UE 槽位和 8 个 CPU 后处理槽位，总墙钟时间 3 分 22 秒。
- 本轮主动避开了正在被其他用户训练占用的 GPU 1；使用空闲 GPU 0/2/3，其中 GPU 0 双 UE 实例，未发生失败或显存不足。
