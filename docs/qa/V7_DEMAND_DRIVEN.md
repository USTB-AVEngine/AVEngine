# v7 demand-driven production

`avengine.timeline.v7_demand` maps every QA-01 through QA-28 family and the five
additional panels to explicit scene requirements. Default family target shares
sum to one and each exceeds 1%; the original 14-question modality schedule stays
30/25/45 over its 20-window cycle. These are requested goals, not realized truth.

Prepare a fresh batch with `tools/timeline/prepare_v7_demand_batch.py`, supplying
original seed recipes, the actual selected-family state, registered asset/audio
catalogs and the existing production input contract. Human motion uses whole
admitted recorded speech, actual moving and static bodies, repeated/staggered
onsets and a native route search biased toward approaching or receding. Animal
motion binds the existing final animal authority. Count scenarios restrict the
complete sound program to class13-capable human sources. Unavailable conditions
remain named deficits. A registered TTS quartet and registered occluder geometry
remain separate native profiles; a single-member motion parent cannot certify
those counterfactual or occluder witnesses.

Pass `--demand-state TASK_OUTPUT/state.json` to the phase2 producer. The next
batch uses selected logical items, never candidate counts or duplicate forms.
Each admitted parent updates the task-owned state atomically; resume replaces
its prior count. Selection receives normalized deficits through the existing
selector's `family_counts` argument and counts real selections across crops.
Caller-supplied prepared demands are retained exactly for a resumable recipe.

Six complete 10-second crops at 0/4/8/12/16/20 seconds reuse a private 30-second
CPU parent. Their common parent identity is retained. They are not independent
parents or a four-member counterfactual group. No training table is exported.

`v7_wet_support` records conservative finite convolution support from actual
assembled nonzero dry samples and the admitted native FIR kernels. Moving
kernels include their measured delay alignment spread. No audibility threshold,
RT60 guess, source waveform or QA predicate changes. Overlapping endpoint events
without isolated per-event support leave the entire wet-tail certification
unavailable, so the original QA gates defer rather than infer early silence.
A fresh audio stage carries this evidence into the existing native adapter.

Native placement, mask, source identity, full utterance, motion, RIR energy,
direction, independent answer replay and scorer gates remain authoritative.
`candidate_audit.demand_realization` records missing requested families beside
actual candidate counts. Native verification is required before claiming that a
requested condition or family is realized.
