# QA-01～24 当前题面的模态依赖（2026-09-06）

本表依据当前实际生成题面和答案形式作设计分析，不以 `required_modalities` 配置替代缺失模态实验。
A 为音频（空间题保留双耳），V 为视频。两者均默认获得相同题面；双模态专指音频+视频。`pixel_visibility`、depth、坐标、事件表和时间索引是验证/真值证据，不是额外默认模型输入模态。

- **AV候选**：设计上需要音频与视觉的信息关联，但必须逐样本排除捷径；本轮尚未完成双模态必要性认证。
- **条件性**：当前题型存在直接的单模态可答情况，需按题面、答案分支和场景条件拆分。
- **A/V**：当前表述属于单模态对照或组件题，不应直接计入双模态主集。
- MCQ 与 Open 分开认证；选项可排除结构会改变单模态条件下的合理基线。

| 编号 | 当前题型 | 设计分类 | 信息依赖与限制 |
|---|---|---|---|
| QA-01 | 外观→是否发声 | AV候选 | 视觉确定外观目标，音频确定该目标是否发声；要包含沉默目标并打散外观—声音映射。 |
| QA-02 | 声音/台词→外观 | AV候选 | 音频确定哪次声音及其来源，视觉读取对应外观；题面给出台词不应泄露说话者外观。 |
| QA-03 | 谁先发声 | AV候选 | 当前答案是衣色/视觉个体身份，须把音频先后顺序绑定到画面人物；仅回答第几路声音则是音频题。 |
| QA-04 | 发声者左右 | A | 双耳音频可提供左右方位；当前题面没有必须读取的视频信息。 |
| QA-05 | 发声区间重叠 | A | 音频即可判断两个事件是否重叠；普通单声道也可作为输入。 |
| QA-06 | 发声期间是否移动 | 条件性 | 动态声学线索可能直接反映运动；监听者/相机运动也会影响声音，不能按题型直接认定双模态必需。 |
| QA-07 | 从哪侧入画 | V | 当前用外观指定目标，入画侧由视频直接确定；若改为声音指定目标才成为AV候选。 |
| QA-08 | 发声时的可见状态 | AV候选 | 音频选择发声目标/时段，视频判断可见状态；须防视野外方位、遮挡声学线索直接泄露答案。 |
| QA-09 | 完全遮挡后是否重现 | V | 当前外观指定目标，遮挡与重现可直接看视频。 |
| QA-10 | 遮挡物身份 | V | 当前外观与帧号已指定目标，视频提供遮挡物身份。 |
| QA-11 | 部分遮挡→完全可见 | V | 当前外观指定目标，状态转变是视觉信息。 |
| QA-12 | 外观→说了什么 | AV候选 | 视觉选择目标，音频提供其台词与归属；仅一个可行说话者等退化样本不能证明双模态必要。 |
| QA-13 | 发声结束后的方位 | AV候选 | 音频确定先前声源，静音后的视觉确定方位；需排除尾音、后续声线索及直接沿用最后声音方位的捷径。 |
| QA-14 | 给定时刻的距离比较 | V | 当前时间与外观候选都已给出，主要依据视觉空间信息；距离必须对输入可辨。 |
| QA-15 | 发声期间靠近/远离 | 条件性 | 音量、混响与双耳动态线索可能支持音频单模态作答；视频有帮助不等于不可缺少。 |
| QA-16 | 声停后的距离变化 | AV候选 | 先用音频绑定目标/锚点，再用静音后的视频比较距离；需排除可预测轨迹与后续声音捷径。 |
| QA-17 | 声停后是否移动 | AV候选 | 音频确定目标与结束时点，视频提供静音后的运动；目标和时段不能已被题面或视觉线索单独揭示。 |
| QA-18 | 指定时刻谁在发声 | 条件性 | 回答具体视觉身份时是AV候选；回答没人或多人发声时可能仅凭音频完成，应分开统计。 |
| QA-19 | 目标首次发声时刻 | AV候选 | 当前目标由外观指定，需视觉绑定个体、音频确定首次发声时点。 |
| QA-20 | 可见候选谁发声/都不是 | AV候选 | 需将声音归属与可见候选匹配；都不是的负例要防A-only视野外方向捷径。 |
| QA-21 | 外观→声音类别 | AV候选 | 视觉确定目标，音频识别其声音类别；只有一个类别或固定衣色—类别映射会形成捷径。 |
| QA-22 | 出现过的实体数/发声个体数 | AV候选 | 视觉统计出现集合，音频与视觉关联确定其中发声集合；MCQ需防只看一个计数就能唯一排除。 |
| QA-23 | 发声事件次数 | A | 当前计数整段音频的事件开始次数，音频即可；独立事件分段仍须可核验。 |
| QA-24 | 先发声者在片尾的可见状态 | AV候选 | 音频识别先发声个体，视觉追踪到片尾；需避免全员同状态等退化样本。 |

当前设计分类为 13 类 AV 核心候选、3 类条件性、3 类音频单模态、5 类视觉单模态。
“生成了有效题/标准答案可判分”与“该题必须双模态”是两个不同指标。
现有 12 题 × 5 输入条件的小批模型结果没有证明双模态优势，也没有完成逐题型×MCQ/Open的条件基线认证。

需要分别报告：
1. 所选 Episode 上的 QA 生成/证据有效率（每段固定尝试24项）。
2. AV核心候选子集的生成有效率（每段13项），仍然不是双模态必要性通过率。
3. 后续逐样本/逐形式的 A-only、V-only、text-only、完整AV与反事实验证结果；未运行保持not_run。

QA-13/16/17 尤其要检查：声音结束且尾音消失后，答案是否仍能由最后的声音位置、默认轨迹或状态延续直接推出。
QA-18 的“无人/多人”分支与具体身份分支需分开。
QA-22 需保留多个与单一可见计数相容的选项，并包含出现数与发声数不相同的样本。

## 原74题批次的实际分布限制

- QA-01 的4个有效实例答案全部为 yes，当前这批不能用来证明音频不可缺少。
- QA-22 的4个有效实例都满足出现数=发声数；需要包含未发声目标、不同可见/发声集合，才能检验联合信息需求。
- QA-18 的4个实例中2个为无人发声，这个答案分支可以仅凭音频判断，应与具体视觉身份分支分开统计。
