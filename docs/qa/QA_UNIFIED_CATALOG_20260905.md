# AVEngine 统一 QA 目录

2026-09-05，根据用户要求统一阅读入口。

以后讨论题目、安排数据和汇报进度，都以这一张表为准。按“究竟问什么”组织，同一题意的不同问法放在一起；已实现、待实现和对照用途分别标明。旧的 12 个 QuestionSpec 是当前代码实现目录，旧的 17 张题卡还包含组合问法、变体和未来想法，不能把两种数量并排当成完成进度。

这里统一的是题目组织和阅读入口。现有代码中的 QuestionSpec 名称、数据编号和接口保持兼容；本文不注册新类型，不把设计稿改称已实现，也不改变已有正式准入规则。

**本篇论文的题目总表。**

例句优先使用当前资产能表达的衣色、位置、说话内容、动静和遮挡。标注“例句”只是说明题意；只有下面单列的原生九题是本轮实际生成结果。当前四个人物没有经过登记和验证的眼镜、手环或衣纹标签，因此不把这些细节写进本篇可落地题目。

| 题目 | 用现有资产表达的例句 | 当前实现 / 这轮进度 | 研究用途和待补变体 |
|---|---|---|---|
| 是否发过声、指定时刻是否发声 | 蓝衣人发过声吗？第 3 秒谁正在说话？ | “是否发过声”已有实现和旧原生样例；指定时刻版尚未接入新三屋 | 时刻锚定与画外发声负例分别记录，不把事实字段存在视为采样完成 |
| 谁先发声 | 最先说话的是哪位？ | 已实现；新三屋原三题模式已跑通，A 的全目标模式也通过 | 若答案要求衣色，要同时绑定发声顺序与外观；旧卡的“先叫的是哪只”归此项 |
| 从声音或台词识别外观 | 说“Please call Stella”的人上衣什么颜色？ | 已实现；A 原生全目标模式覆盖蓝、粉、绿、白四个人 | 衣色是受控资产标签，仍需实际画面可答；“没有人说过”是音频充分对照 |
| 从外观识别说话内容或声音类别 | 蓝衣人说了什么？深色狗发出什么声音？ | 人物唯一台词版已实现，A 全目标模式四人通过；一般声音类别/多源变体未在此轮实现 | 台词和一般声音类别有不同素材要求，不把后者算作前者已经覆盖 |
| 发声发生在什么时候 | 蓝衣人第一次说话在第几秒？ | 数值时刻题属于设计/待接入；不是当前稳定 QuestionSpec 类型 | 现有事件时钟可作真值来源，还需要采样、答案定义及实际评测 |
| 两段声音有没有重叠 | 蓝衣人和白衣人的话重叠过吗？ | 已实现并有旧原生样例；新四人样例的 dry 语音按顺序播放，此轮未出该题 | 声音重叠是音频对照；发声区间重叠与混响尾音重叠分开 |
| 在场、发声个体和声音事件的数量 | 有几个人？其中几人说过话？一共几次发声？ | 旧产线有相关计数设计/产物；未统一接入本轮新三屋 QuestionSpec adapter | 个体数和发声次数不能混算；仅数几声是音频对照 |
| 发声者相对听者的方位 | 这句话来自左边还是右边？说完话的人在片尾哪边？ | 左右判断已实现并有旧原生样例；错时、多扇区/数值角度版仍待实现 | 发声当时的方向可由双耳音频提供；静默后的方向是不同时间条件的变体 |
| 目标相对听者/另一目标的距离及变化 | 第 2 秒谁更近？说完话后那人比发声时更近还是更远？ | 旧挖矿设计/部分相关产物存在；本轮没有接入统一距离题 | 给定时刻距离可作视觉对照；声中远近变化可含声学线索；错时版另记 |
| 发声时或发声后是否移动 | 说这句话时他在动吗？说完之后动了吗？ | 发声期间动静已有实现和旧原生样例；静默后动静是待接入变体 | 原卡 6 和卡 10 的发声期间动静合并，不重复算题；移动音频线索需如实说明 |
| 从画面哪边进入 | 那个人从画面哪侧进入？ | 已实现并有旧原生样例；新四人静坐片段尚未重出 | 视觉对照，也可作为跨模态组合中的后续状态 |
| 目标在某时刻的可见/遮挡状态 | 说话的人被部分遮挡、完全遮挡，还是已经出画？最先说话的人片尾是什么状态？ | 发声时状态已有实现；先发声→片尾状态的链式采样还未完成 | 自然桌椅遮挡和画外允许存在，是否可答由这道题决定，不做全房间失败条件 |
| 完全遮挡后是否重新出现 | 那个人完全被遮挡后又出现了吗？ | 已实现并有旧原生样例；只覆盖单个 Episode | 单片段可见性序列，不称跨段或长期记忆 |
| 部分遮挡后是否完全可见 | 那个人从部分遮挡变成完整可见过吗？ | 已实现并有旧原生样例 | 保留独立的状态转移定义，不与“完全遮挡后重现”混为一谈 |
| 是什么挡住了目标 | 桌子还是椅子挡住了那个人？ | 已实现并有旧原生家具身份样例；新三屋尚未重出 | 可作为组合题的后续一步；需要可靠家具语义，无需人物与家具动作交互 |

表里的“旧原生样例”是实际保留的引擎产物及当前 validator 检查，不代表该题已在本轮三套新房间重新生成或待评测模型已答对。对于“旧产线有相关产物”的条目，本轮没有重测其历史模型分数。

**本轮可以直接看的实际问答。**

A 房间的正确姿态 v3 原生视频和最终双耳音轨，显式 all-speaking-targets 模式实际生成 9 题，evaluator pass 9、deferred 0。它包含一次“谁先发声”以及四组双向问答：

| 实际题目 | 实际答案 |
|---|---|
| 谁先发声？ | 蓝衣人物 |
| 蓝衣人说了什么？ | Ask her to bring these things with her from the store. |
| 说上一句的人上衣什么颜色？ | 蓝色 |
| 粉衣人说了什么？ | She can scoop these things into three red bags, and we will go meet her Wednesday at the train station. |
| 说上一句的人上衣什么颜色？ | 粉色 |
| 绿衣人说了什么？ | A new school will be built. |
| 说上一句的人上衣什么颜色？ | 绿色 |
| 白衣人说了什么？ | Please call Stella. |
| 说上一句的人上衣什么颜色？ | 白色 |

“上一句”是表内展示缩写；真实反向题通过对应 sound_asset_id/唯一台词绑定目标，不让模型依赖表格顺序。三类题目覆盖四人后是九道实例，不是九种新能力。当前三屋仍复用同一批声音、人物和顺序，不能据此声称身份、台词和生活活动已经有足够多样性。

颜色由作者控制的资产信息提供，当前 adapter 用通用 coat_value 存储衣色，并从现有资产 ID 的颜色后缀取值。原生 mask 证明人物的可见/遮挡状态，不自动证明上衣细节足够可见或模型识别正确。当前结果仍是 research_only。

**如何理解组合题，避免再次出现两套目录。**

“最先说话的人，片尾是什么遮挡状态？”是一个具体组合问法：先用发声顺序确定目标，再查询它的片尾状态。它统一归在“目标在某时刻的可见/遮挡状态”，备注需要发声顺序；不要把题卡编号再独立计入已实现能力数。将来新增问法，先归入本表现有题意，只有答案语义不同才增加新条目，并明确工程状态。

这份目录不要求所有题目都同时依赖音频和视频。单模态对照、跨模态绑定、时间变体和组合问题的用途分别写明。是否足够验证本篇主张，仍需要真实可答性和现有缺失模态评测；evaluator 生成正确真值不等于模型具备能力。
