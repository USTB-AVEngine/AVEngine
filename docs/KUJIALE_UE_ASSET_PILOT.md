# 酷家乐 UE 动物和物件小批试产

本工具链仅在授权的 48g、本 worktree 和 ue_round21_pilot 内进行非商业研究试产。生产渲染仍为 UE/SPEAR；没有训练表导出、CCI 转移或 push。

入口是 tools/timeline/v7_kujiale_production_v2.py 的 --pilot-root 分支。它复用 33b5b12 的登记人物生成器、录音、原生 RIR、视频时钟、候选题、四成员反事实和封存门禁。动物及物件绑定实际 UE 网格和发声组件；动物使用登记嘴部坐标，物件使用允许声音类别和机身/喇叭坐标，空调只作为静音摆设。导入的 Content、Binaries 和 Source 保持旧工程只读链接，运行目录、配置、缓存和日志私有。

prepare_kujiale_asset_pilot.py 从已准入个体中选择每种身体和物件类型，依据实际 UE LOD0 建立支持面和碰撞计划。计划只是待原生同场验收的候选，不是通过证据。每个场景重新检查网格边界、附件贴附、尺寸、三个完整视角、碰撞、发声点、实际 GPU UUID、RIR 方向，以及 450 帧实际网格和发声点。人物用已测地板基准和地面支持语义，不允许床面；本轮额外要求脚底误差 ≤15 mm。源资产与登记标签不修改。

物理资产先前的颜色分歧不拒绝资产。依赖颜色的候选题必须使用该窗口实际 UE 像素复测，分歧候选保留丢题原因。生产高光门槛保持 ≤2%。独立真值模块对保留题逐项重放未修改的 v6 权威候选；STARSS 和登记声音类别通过另一套 100 ms 活动并集、物理演员集合、相机几何投影和选项值查找重算。

修复规划先检查生产相机位置的原生几何视线和同一门槛的实际 RIR。人物不得挡住环境实体的视线。pilot_binding_coverage 相机用实际已验收人物的位置保持说话期间的绑定视角，随后获取全方位出场；所有视角和声学旋转仍取实际 UE 读回。完整四成员的每窗口五道绑定题要求没有降低。不能形成足量绑定题的场景不得封存。

已完成阶段通过不可变 pointer 续用。失败尝试和完整产物不覆盖。不同物理 GPU 配置不能偷偷改写旧配方；续跑使用原卡号，新的布局使用新父场景尝试 ID。作业在 JOBS.json 登记明确 PID、命令和日志，以 nice -n 10 启动，只使用物理 GPU 2、3。每次 UE 启动检查显存，新增逻辑产物限 60 GB，/data 余量低于 150 GB 时停止。协调器截止前清理自己启动的进程树。

report_kujiale_asset_pilot.py 生成单文件中文内嵌图片页面和对应 JSON 数字来源。封存通过、仅阶段通过和失败尝试分别说明；仅独立重算通过的封存计入父场景通过和覆盖。详细本轮状态请读取产物目录 PROGRESS.md、JOBS.json 和最终报告，文档不预先宣称试产成功。
