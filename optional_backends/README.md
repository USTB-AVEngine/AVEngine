# Optional backend boundary

Optional experimental integrations must be explicitly selected by a caller.
UE, SPEAR, gpuRIR and generative asset tooling are not installed, configured or
loaded by the Habitat-native bootstrap. An optional backend cannot redefine
the central entity, room, timeline, source, flag or evidence contracts.

当前保留但不默认应用的外部源码补丁见
[`third_party_patches/README.md`](third_party_patches/README.md)。
